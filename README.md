# e-commerce-fake

Protótipo de loja virtual com catálogo e fluxo visual de pedido em JavaScript.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `css/style.css`; interação em `js/script.js`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`.
